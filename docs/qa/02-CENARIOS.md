# 02 — Matriz de cenários por jornada

Base: commit `281cd07`. Cada linha cruza **ator × estado do dado × entrada × condição** e segue o caminho
de ponta a ponta (interface → hook → chamada → backend → banco → resposta → interface).

- **EXECUTADO** = comando, consulta ou request rodado nesta sessão, com saída vista.
- **RASTREADO** = caminho seguido lendo o código que roda, sem execução.
- Linha com `divergiu = sim` virou achado em `03-ACHADOS.md`.

**Totais:** 293 cenários — **50 EXECUTADO**, **243 RASTREADO**; 249 divergiram do esperado.

## Por que tão poucos EXECUTADO

Três acessos que permitiriam executar de verdade não existem nesta sessão, e o erro exato está em
`01-INVENTARIO.md` §11: (1) nenhum MCP aponta para o Supabase oficial `iecgydonctmabiijadsf`, então
nenhuma consulta rodou no banco; (2) o proxy desta sessão recusa `iecgydonctmabiijadsf.supabase.co`
(`403 Forbidden (agent proxy: no rule or network setting allows this host)`), então nenhum request chegou
às edge functions publicadas; (3) o mesmo acontece com `lalamove-v2.vercel.app`, então o front em produção
não foi aberto. O que foi executado: a suíte local (1050 testes), typecheck, lint, build, os guardas de
`scripts/ci/`, os geradores de inventário, e a leitura da API do GitHub (incluindo o log do job de
integração do CI, que é a única evidência de comportamento real das edges publicadas).
